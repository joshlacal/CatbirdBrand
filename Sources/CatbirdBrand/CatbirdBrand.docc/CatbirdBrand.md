# ``CatbirdBrand``

Generated Catbird design-system tokens for iOS, iPadOS, watchOS, macOS, tvOS and visionOS apps.

## Overview

The token types are generated from the Pkl modules that define the Catbird brand and decoded lazily from a bundled JSON snapshot. Use the ``Brand`` namespace to reach colors, type, spacing, radii, motion and materials. See the package README for usage and for how to regenerate the tokens after a change.
